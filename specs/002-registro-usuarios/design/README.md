# Referencias de diseño de Registro

Esta carpeta reúne los resultados de la extracción de Figma para la funcionalidad Registro.
Las consignas del usuario están fuera de `specs/`, en el
[harness de Figma](../../../harness/sdd/figma/registro-usuarios.md).

**Origen esperado**: [04 Registro](https://www.figma.com/design/f7uDsv8sh6ZOtK2OitTqtg/Billetera-Virtual---Prototipos?node-id=31-2),
archivo `f7uDsv8sh6ZOtK2OitTqtg`, nodo `31:2`.

**Estado**: extracción realizada el 2026-10-15 por Claude Code desde una copia del
archivo (`pMArqPGrwekkonUVIZLSn4`, mismo nodo `31:2`). La cuenta no tiene acceso al
original. Origen, archivos y limitaciones en [extraction-notes.md](extraction-notes.md).
Codex recibió y contrastó los archivos con la spec el 2026-10-15. Las decisiones y
adaptaciones de accesibilidad están en `../research.md`; la aprobación humana sigue pendiente.

## Archivos de referencia recibidos

- `design-context.md`: contexto visual y textos obtenidos del diseño.
- `metadata.xml`: estructura devuelta por MCP, si está disponible.
- `design-tokens.json`: variables y estilos efectivamente extraídos, si están disponibles.
- `registro-desktop.png`: exportación o captura guardada del frame.
- `assets/`: recursos exportados que sean necesarios.
- `extraction-notes.md`: origen, fecha, herramientas, archivos guardados y limitaciones.

Se verificaron estos archivos y la captura 1440 × 1024. `design-tokens.json` no contiene
variables porque el frame no las utiliza. No hay frame móvil ni estados interactivos;
se derivan de los requisitos y los componentes existentes. El original no pudo verificarse
directamente; se trabaja con la instantánea de la copia, que conserva el nodo `31:2`.
